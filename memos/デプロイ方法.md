# デプロイ方法

- 開発時は`npm run dev`でVite開発用サーバを起動してアプリを動かす
- 本番環境へのデプロイ方法についてまとめる
  - 本番環境はSpring Bootに組み込まれたApache-Tomcatを想定

## 1. ビルド

- `npm run build`でアプリをビルドする
- ビルド後、以下のフォルダ・ファイルが生成される

```tree
  dist/
  ├── assets/
  │   ├── index-BhEQyf6K.css
  │   └── index-CXgKb70-.js
  └── index.html
```

## 2. デプロイ

- Spring Bootの静的ファイルとして配置する
  - Spring Bootは以下の場所に置かれたファイルを自動的に静的配信する
    - `src/main/resources/static/`
    - `src/main/resources/public/`

### 2-1. 最もシンプルな方法

- `/dist`の中身を丸々`/static`に配置する

```tree
static/
├── assets/
│   ├── index-BhEQyf6K.css
│   └── index-CXgKb70-.js
└── index.html
```

### 2-2. React Routerに対応した方法

- React Routerを使っていて、例えば`/home`や`/user/123`にアクセスしたとき、デフォルトではSpringはファイルを見つけられず404を返してしまう

- 回避策
  - Java Configを設定する

  ```Java
    @Configuration
    public class SpaRedirectConfig implements WebMvcConfigurer {

      @Override
      public void addViewControllers(ViewControllerRegistry registry) {
        registry
          .addViewController("/{spring:\\w+}")
          .setViewName("forward:/index.html");

        registry
          .addViewController("/**/{spring:\\w+}")
          .setViewName("forward:/index.html");

        registry
          .addViewController("/{spring:\\w+}/**{spring:?!(\\.js|\\.css|\\.png|\\.ico)$}")
          .setViewName("forward:/index.html");
      }
    }
  ```

  ```Java
    // 簡易版
    @Controller
    public class SpaController {

        @RequestMapping(value = "/{path:[^\\.]*}")
        public String forward() {
            return "forward:/index.html";
        }
    }
  ```
